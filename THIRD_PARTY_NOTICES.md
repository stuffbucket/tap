# Third-Party Notices

The canonical redistribution notice is [`THIRDPARTYNOTICES`](THIRDPARTYNOTICES), generated by `bun scripts/generate-notices.ts`.

It contains component names, source locations, SPDX-style license identifiers, important redistribution notes, and the complete locally available license texts for direct runtime and bundled dependencies. Release artifacts also include machine-readable SBOMs, lockfiles, Ghostty/ghostty-web receipts, the FFmpeg build configuration, and an inventory of bundled dynamic libraries.
